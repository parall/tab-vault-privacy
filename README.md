# 标签页保险箱 Tab Vault · 隐私政策

本仓库用于托管 Chrome 扩展「标签页保险箱（Tab Vault）」的隐私政策公开页面，供 Chrome 应用商店审核与用户查阅。

- 在线页面：`index.html`（GitHub Pages 首页）
- 适用产品：Chrome 扩展「标签页保险箱」v1.0.0 及后续版本
- 最后更新：2026 年 10 月 21 日

## 核心说明

本扩展不联网、不上传、不统计。扩展代码中不含任何向外部服务器发送数据的网络请求，所有快照仅保存在用户本机的浏览器 IndexedDB（库名 `tabvault`）中。扩展不读取网页正文、表单内容、Cookie 或密码，在无痕模式下不运行。

## 更新方式

政策内容变更时，直接修改 `index.html`，并同步更新页面顶部的「最后更新」日期与页脚日期。若变更涉及数据的收集或外传，需在扩展更新说明中显著提示用户。

---

本仓库不包含扩展源代码，仅为隐私政策页面的静态托管。
